# Rules summary (source: ../wiki/Official-Rules.md — official text prevails)

## Dates (Chile = PT + 4h in Oct)
- Submission closes: Oct 27 2026 23:59 PT (Oct 28 03:59 Chile). Target: submit Oct 26.
- Judging: Oct 27 – Nov 10. Demo must stay live and open until Nov 10.
- Winners announced by Nov 20.

## Challenge: one pipeline, five stages
Ingest synthetic events live → Interpret into stats/patterns → Explain why moments
matter → Render on-screen alongside the match → Personalize (analyst vs casual fan,
favorite club/player, player-focus mode, language).
Suggested features: player tagging w/ speed/distance thresholds, pass distance/
accuracy/difficulty, ball and shot speed, auto-eventing from video (optional),
narratives + recaps, control vs chaos / pressure / rhythm, multi-language.

## Data
- Must be synthetic and football-realistic. Nothing is provided by organizers.
- Creating/extending synthetic datasets is itself judged ("data innovation").

## Judging (stage 1 pass/fail on theme + tech; stage 2, 20% each)
1. Technological implementation: synthetic data quality, engineering practices,
   use of hero tech (Foundry, Agent Framework, Azure MCP, Copilot agent mode,
   Fabric, Azure apps/AI/databases), maintainable documented code.
2. Agentic design & innovation: orchestration, MCP, multi-agent collaboration.
3. Real-world impact: production-deployable, meaningful problem.
4. UX & presentation: intuitive UI, clear video, frontend/backend balance.
5. Adherence to category.
Ties broken in that criterion order.

## Target category
Best Multi-Agent System: distinct agent roles, shared state, handoffs,
failure recovery, end-to-end outcome a single agent couldn't match.
(Max: 1 Grand Prize + 1 Category Prize.)

## Submission checklist
- [ ] New project (created after Sep 29 2026); open source only if extended + licenses respected
- [ ] Pitch: what it does, problem, Microsoft/Azure tech used
- [ ] Video < 2 min, public URL (YouTube/Vimeo), shows it running, no third-party marks/music
- [ ] Public GitHub repo
- [ ] Working demo link open to judges, free, no restrictions (no IP allowlist)
- [ ] Testing instructions
- [ ] Everything in English
